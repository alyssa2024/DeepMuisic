## 2. 本次范围 — 要做的两件事

### 任务 A:basin 内换 per-sample MNN 精修(主任务)

**目标:** 用已验证的 FR-basin 做初值,per-sample 连续优化把 basin 内频率做到 ~0.11 量级,
同时拿到幅值与未知阶数 K。

**信号模型(用户的"旋转因子"):**
```
forward:  ŷ(t_n) = Σ_k a_k · exp(j·2π·f_k·t_n)      # 神经元=旋转因子, 权重=复幅值 a_k
loss   :  ‖y - ŷ‖² / σ²  (+ 稀疏先验/剪枝定 K)
```

**固定流程(每样本):**
1. FR-basin 给频率初值 `f_k^0`(选中 basin 的峰)。
2. **顺序初始化(按置信度,借 von Mises MAP §4.3):** 按先验置信/SNR 从强到弱排序分量,
   先定最稳的(如基音 / 强先验阶),再逐个加入弱分量——减少"其他频率还没准时"的条件误差。
   替代按幅值贪婪的剥离顺序。
3. 给定 `f_k`,**复幅值 a_k 闭式 LS**(线性,profile 掉)。
4. **多分量用条件交替,不用 CLEAN 剥离(借 von Mises MAP §4.2):** 固定其他频率,在正交补
   `Π⊥_{A_i}` 上更新单个 `f_k`(profile-LS 条件代价),逐分量轮转至收敛。比"减重构再找"干净、
   无伪影累积,且形式可微、直接接 GN。
5. 对 `f_k` 做 **GN/Adam 少步精修**(从捕获域内初值起,1~few 步即可;不是从零跑 399 步)。
6. **定阶 K —— 分两层(见 §3.5),不靠单一幅值阈值。**
7. 连续不确定性 = 收敛点 **Hessian/Fisher 的 CRB**(解析,不需变分)。

> 求解器是你的几步 GN,**不是** von Mises MAP 那套 10 层 ×500 点全域网格(它每条 ~740 ms,
> 因为从 [-π,π) 冷启动)。借它的目标结构与分层逻辑,不借它的网格搜索——你有 FR 初值在捕获域内。

**验收线:**
- `freq_mae` 在 c16@20dB 上达到 **≤0.13(对齐/超过传统 LSF 0.127)**,目标 **~0.11**
  (自由参数已侧证可达),理想逼近 CRB 0.099。**0.16 是及格下限,不是目标**——做不过 LSF
  就失去"比传统方法更好"的立项意义。
- 不依赖已知频率数 K(由 §3.5 两层定阶得出)。
- selection 的【选基音/选 basin】指标不退化(被选 basin 的 top1/basin_hit 仍 =1.0);
  注意本次为支持可变 K **会小改 selection 结构**(§3.5 层 1),非"完全不碰"。

### 任务 B:先验对齐(独立 bug,必须修,可并行)

**Bug:** 数据生成先验 = 中心 ±5% **均匀**;模型/推断先验 `p(δ)` = **标准高斯**。错配。

**要做:**
- 把推断侧 `p(δ)`(及任何下游贝叶斯打分 / 残留 Laplace 项用到的先验)改成
  **与生成一致的 ±5% 截断均匀**(或方差匹配该带宽的宽高斯,作为兼容退路)。
- 确认**合成数据生成先验**与**下游打分先验**用的是同一个带,集中到一处定义、两边引用。
- **先验放对位置(关键,借 von Mises MAP §7.4 PLEDGE 教训):** basin 内连续精修的 `p(δ)`
  = 匹配生成的 **±5% 截断均匀** —— 在 von Mises 框架里这是 κ→0 的近无信息端,即 basin 内
  **似然主导、先验几乎不插手**。**软物理先验(Campbell/阶次)只作用在 q(z) 选洞的打分上,
  绝不进 basin 内连续精修。** 硬把先验中心当真值/惩罚过强,数据充分时反而压着估计不走到 CRB
  (PLEDGE 正是此病;你原"标准高斯拉 δ→0"是它的一个实例)。
- **绝对 Hz 偏移不要套 von Mises:** Δf=f−g(Ω) 在物理频率区间无 2π 周期等价,用截断均匀/截断高斯。
  von Mises 只配真有周期的量(相位 / engine order / alias index)。

**验收线:**
- 生成与推断先验在代码里**同源**(单一真相源),grep 不到第二处硬编码的高斯 σ。
- 若 q(z) 打分用到先验,改后 selection 指标不退化。

## 3. 任务 A 的已知坑(plan 必须含这个核对步)

**初值捕获域核对 —— 已执行(2026-06-27),结论如下。**

> **概念厘清(此前 plan 把两个量混了):** 「±5% 真值跨度」和「GN 初值误差」不是一回事。
> - **±5% 跨度 = 真频相对 basin 中心的漂移(8.3 / 17.1 / 31.8 / 43.6 Hz @ 中心 167/341/635/872)。
>   这是 q(z) selection 要解决的问题,而它已解决(basin_hit=1.0)——FR 候选跟着真频跑,
>   选中的候选已落在真频附近。这个大跨度【不是】GN 的初值误差。**
> - **GN 真正的初值误差 = FR 检测误差 = 选中 FR 候选离真频的距离。**

**实测(300 样本,c16@20dB,include_local_time):**
- FR 网格 spacing = 1.951 Hz,半 bin = 0.976 Hz。
- **FR 检测误差(=GN 初值误差):mean 0.52 / median 0.49 / p95 1.11 / max 1.84 Hz。**

**判定:**
- **主体(~95%)样本:FR 峰直接作初值即可** —— 0.52 Hz 远小于半 bin,在 GN 捕获域内,无需插值。
- **尾部(~5%,初值误差 >1 Hz,接近/超过 1 bin):有掉出捕获域、GN 收敛到邻 bin 伪峰的风险。**
- **结论:把 FR 峰 sub-bin 插值(抛物线/重心)作为【标准前处理】**(不是条件触发):对所有样本
  无害、对尾部关键(把 p95/max 从 ~1.1/1.8 拉回 ~0.2 量级),零成本。再交给 GN。
- 即 findings 方向 A 作为 MNN 的初值前处理,**不是**替代 GN。

## 3.5 定阶(估计 K)— 分两层(本次决策)

**为什么不能只靠 per-sample 幅值阈值(BTT 特有难点):**
- 欠采样混叠 → 多余旋转因子易去拟合 **alias 假峰**,其幅值未必小,裸阈值剪不掉。
- 真分量幅值差异大(强基音 + 弱高次模态)→ 单一阈值会 **漏检弱真模态**。
- 故定阶看的应是「加这个分量值不值」(残差下降 vs 复杂度代价),而非绝对幅值。

**已查清的结构事实(决定为何要破 F2):**
- q(z) 现在是 **K=4 固定 slot**:`component_embedding=Embedding(4)`(L1042),
  `log_softmax(z_logits, dim=-1)` 在 **候选维**上(L1386)——每个 slot **强制选一个候选,
  无"空 slot"出口**。现有 z_logits **无法零改动读出可变 K**。

**层 1 — selection 层定粗 K̂(需小改 q(z),破 F2 一次,借 SignalNet #3 detection 思路):**
- `component_embedding`: `Embedding(4)` → `Embedding(K_max)`(如 8);向后兼容 K=4。
- 新增 **occupancy head**(每 slot 一个标量 sigmoid logit,与现有 z_head「选哪个候选」正交)。
- 训练:数据生成改为 **可变 K∈[1,K_max]**,occupancy 用 **BCE** 监督;现有候选选择损失不变。
- **K̂_粗 = sigmoid(occupancy)>0.5 的 slot 数。** 几何鲁棒(在混叠几何上训练),比 per-sample
  幅值阈值稳。
- ⚠️ 这是**唯一**对 selection 的结构改动;F2 的「被选 basin 命中率」仍须保持(回归测试)。

**层 2 — MNN 层定精 K̂(per-sample,借 NOMP #14 / MDL #5,替代裸幅值阈值):**
- 在层 1 给出的粗 K̂ 基础上,per-sample 优化后用 **MDL/AIC** 或 **NOMP 虚警控制阈值** 决定
  每个分量「留/删/与近邻合并」。阈值从噪声水平 σ² 导出,**不手调**,且能扛混叠假峰
  (假峰残差下降不足 → 被复杂度惩罚剪掉)、护住弱真模态。
- 合并近节点(借 MNN #1 第 6 步):两分量收敛到同一频率则并一个。

**职责切分:** 层 1(摊销、几何鲁棒)给「大概几个、在哪些 basin」;层 2(per-sample、统计严谨)
做「精确留删合并」。两层都不靠绝对幅值阈值。

**验收线(定阶):** 可变 K∈[1,K_max] 测试集上 **count_exact_rate / count_mae**(借 findings
DeepFreq 诊断的口径);层 1 改动后,固定 K=4 子集的 basin 命中率不退化。
